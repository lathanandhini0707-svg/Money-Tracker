How sharing works:

Export your budget as a data file. You can send that file through WhatsApp, email, Drive or any other method. The receiver can open this website and import the file to view the same transactions, loans and savings.

Important: this is file-based sharing. If two people need automatic live syncing, a cloud database/login system is required.

Data Safety

Keep your exported data file private because it may contain personal financial information. Do not upload personal budget files to a public GitHub repository.
